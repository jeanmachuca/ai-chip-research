# Submissions Directory

This directory contains packages for research dissemination to external repositories.

## Contents

- `zenodo/` - Zenodo submission packages with metadata JSON
- `arxiv/` - arXiv source files and submission scripts
- `github-releases/` - GitHub release archives with source bundles

## Pipeline

Submissions are generated by `scripts/generate_paper.py` and deployed via `.github/workflows/publish.yml`.
