# LaTeX Sources Directory

This directory contains LaTeX templates and bibliographies for paper generation.

## Contents

- `templates/` - IEEE conference paper templates
- `bibliography.bib` - Main bibliography file (BibTeX)
- `figures/` - Figures referenced in papers (LaTeX-compatible formats)
- `style/` - Custom LaTeX styles and definitions

## Usage

Papers are generated by `scripts/generate_paper.py` and can be compiled with:

```bash
latexmk -pdf papers/paper_<model_name>.tex
```
